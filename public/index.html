Method 1: Instant 5-Second Command

Map Virtual Drive via Command Prompt or PowerShell

On your laptop, open Command Prompt or PowerShell and run this single command:

net use Z: http://127.0.0.1:3000/webdav /user:admin codecloud123 /persistent:yes
1
Open in VS Code:

In VS Code on your laptop, click File ➔ Open Folder... ➔ Navigate to This PC ➔ Select Z:\ (or specific project folder inside). Alternatively run: code Z:\Welcome-Project.

2
Open in Sublime / Notepad++ / JetBrains:

Click File ➔ Open Folder and pick drive Z:\. That's it! Any file you click will be streamed and saved in real-time over the network.

3
Unmount / Disconnect when done:
net use Z: /delete /y
💡 Graphical Method (File Explorer):

Open File Explorer ➔ Right click This PC ➔ Click Map network drive... ➔ Pick Drive Z: ➔ In Folder field paste: http://localhost:3000/webdav ➔ Check Connect using different credentials ➔ Enter username admin and your password.

Mount via macOS Finder

1

Open Finder on your Mac laptop.

2

Press Command ⌘ + K (or click Go ➔ Connect to Server...).

3

In the Server Address box, enter:

http://127.0.0.1:3000/webdav
4

Click Connect and enter username admin and password.

5

The drive mounts under /Volumes/webdav. Open it in VS Code, Sublime, or Cursor!

Mount via davfs2 on Linux

Mount CodeCloud into a local directory using standard WebDAV:

sudo mount -t davfs http://127.0.0.1:3000/webdav /mnt/codecloud -o username=admin

Or open your file manager (Nautilus, Dolphin) and press Ctrl + L ➔ enter dav://127.0.0.1:3000/webdav.

🌐 100% Free & No Port Forwarding

How to Connect From School Over the Internet

To reach your home PC from school Wi-Fi without configuring router port forwarding, use Cloudflare Tunnel. It gives you a free, public https://... link with zero router setup!

1
Start the Tunnel on your Home PC:

Run this in Command Prompt on your home PC while CodeCloud is running:

npx -y cloudflared tunnel --url http://localhost:3000
2
Get Your Secure HTTPS Link:

Cloudflare will print a URL like: https://your-name-1234.trycloudflare.com.

3
Connect From Your Laptop at School:

On your school laptop, map the drive using the HTTPS link:

net use Z: https://YOUR-SUBDOMAIN.trycloudflare.com/webdav /user:admin codecloud123

Because Cloudflare provides a real SSL certificate, Windows connects effortlessly!
